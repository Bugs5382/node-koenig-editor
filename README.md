# node-koenig-editor 🧩

> 🧭 Ghost's Koenig editor on Lexical 0.52 and React 19, packaged for reuse, with optional Yjs collaboration.

## 📦 Install

```bash
npm install node-koenig-editor
```

## 🚀 Usage

```ts
import { hello } from "node-koenig-editor";

hello("world"); // "Hello, world!"
```

## 🛠 Develop

```bash
npm install
npm run build      # tsdown -> dist (esm + cjs + d.ts)
npm test           # vitest
npm run lint       # eslint + prettier
npm run docs       # typedoc -> docs
```
